# تعديلات معتمدة على المستند

هذه القرارات اتُّخذت بعد كتابة `brief.md` وتتقدّم عليه عند التعارض.

## 1. النظام خاص بالكامل

- العميل لا يرى أي صفحة. تُلغى الصفحات العامة الثلاث: تقرير العميل (13)، التسجيل عبر QR (14)، عرض السعر للعميل (15).
- يُلغى معها: جدول `audit_reports` وتتبع فتح التقرير، وحقل `quotes.public_token`، والقيمة `qr` في `leads.source`، وإضافة «كرت QR».
- قاعدة «العميل يصبح حاراً إذا فتح تقريره» تُلغى؛ يبقى «إذا رد».

## 2. عرض السعر يُرسل ملف PDF فقط

- الشاشة 11 (عرض السعر): اختيار الخدمات من الكتالوج، الكمية، سعر الوحدة، خصم (بدون / 5% / 10% / 15%)، صلاحية (7 / 14 / 30 يوم)، ملاحظات، والمجموع الشهري ومجموع المرة الواحدة يتحدثان مباشرة.
- معاينة PDF ثم «مشاركة PDF عبر واتساب» عبر Web Share API (`navigator.share({ files })`)، و«تنزيل PDF» كبديل. رابط wa.me لا يرفق ملفات.
- بعد المشاركة: نافذة سفلية «هل أرسلت العرض؟»، وعند التأكيد: المرحلة `proposal` + مهمة «تابع رد العرض» بعد 3 أيام.
- رقم العرض بصيغة `Q-YYYY-NNN`.
- الأسعار وضريبة القيمة المضافة لم تُحسم: اجعل الضريبة إعداداً (لا تُضاف افتراضياً).

## 3. بدون خرائط حالياً

- لا شاشة خريطة ولا وضع جولة ولا عرض «قائمة/خريطة».
- يبقى التقاط الموقع (lat, lng) في فورم العميل الجديد، وزر فتح موقع المحل في خرائط قوقل اختياري لاحقاً.

## 4. قرارات ما زالت مفتوحة (استخدم بدائل مؤقتة)

- اسم النظام ولونه وشعاره: الاسم المؤقت «ميداني»، واللون الأساسي `--action` (حبر داكن) مؤقت.
- قائمة الخدمات وأسعارها: بيانات تجريبية في seed.
- مزود الذكاء الاصطناعي: اجعل `generate-message` تقرأ المزود والمفتاح من الأسرار، ومع قالب احتياطي عند الفشل.
- اسم العلامة والتوقيع في ملف PDF: من جدول `profiles`.
