# الشاشات المصممة

كل ملف في `design/screens/` شاشة واحدة. الجوال بعرض 390، والديسكتوب صفحة مرنة مصممة على 1440 مع شريط جانبي يميناً.

## الجوال

| الملف | الشاشة | أهم ما فيها |
|---|---|---|
| `Login.dc.html` | 1 · الدخول | بريد وكلمة مرور، بدون تسجيل جديد |
| `Main.dc.html` | 2 · اليوم | 3 عدادات، هدف الأسبوع، متأخرة (warning)، متابعات اليوم مع واتساب، عملاء حارّون |
| `NewLead1.dc.html` | 3 · عميل جديد — البيانات | شبكة النشاط، صفة المسؤول، الجوال، مفتاح موافقة واتساب، أفضل وقت، الموقع، شريط تقدم 4 خطوات، حفظ مسودة |
| `NewLead2.dc.html` | 3 · التقييم | TriSelect لكل بند بوزنه، ScoreBar ثابت أعلى الشاشة يُحسب مباشرة، بنود النشاط ثنائية ولا تدخل في الدرجة |
| `NewLead3.dc.html` | 3 · الملاحظات | الملاحظة الأبرز (90 حرفاً)، ملاحظة صوتية تتحول لنص، ملاحظات حرة، صور وفيديو، تنبيه مهمة العينة |
| `NewLead4.dc.html` | 3 · الخدمات | خدمات مقترحة من نقاط الضعف مع السبب، قابلة للإلغاء، القيمة المتوقعة، «احفظ وولّد الرسالة» |
| `Message.dc.html` | 4 · الرسالة | النبرة (ودّي/رسمي/مختصر) تغيّر المسودة، عدّاد الأسطر، أعد الصياغة، نسخ، إرسال عبر واتساب |
| `SentConfirm.dc.html` | 4 · تأكيد الإرسال | BottomSheet «هل أرسلت الرسالة؟» + المتابعتان بعد 3 و7 أيام |

| `Lead.dc.html` | 6 · صفحة العميل | واتساب/اتصال/عرض سعر، الخطوة القادمة، تبويبات: نظرة عامة، الخط الزمني، الرسائل، المهام، العروض |
| `Pipeline.dc.html` | 7 · Pipeline | شريط مراحل أفقي، LeadCard compact، تمييز الراكد أكثر من 7 أيام |
| `Tasks.dc.html` | 8 · المهام | متأخرة / اليوم / قادمة، إنجاز بالضغط، زر الإجراء المناسب |
| `Quote.dc.html` | 11 · عرض السعر | الخدمات، كمية، سعر، خصم، صلاحية، ملاحظات، مجاميع مباشرة |
| `QuotePreview.dc.html` | 11 · معاينة وإرسال | ورقة PDF، مشاركة عبر واتساب، تنزيل، تأكيد الإرسال |
| `Settings.dc.html` | 12 · الإعدادات (أساسية) | الملف الشخصي، الخدمات، الأنشطة، القوالب، الهدف، المظهر، تصدير CSV |
| `BottomNav.dc.html` | الشريط السفلي | اليوم، العملاء، عميل جديد (وسط بارز)، Pipeline، المزيد |

## الديسكتوب

| الملف | الشاشة |
|---|---|
| `DeskSidebar.dc.html` | الشريط الجانبي: اليوم، العملاء، Pipeline، المهام، لوحة الأرقام، عروض الأسعار، الإعدادات |
| `DeskToday.dc.html` | اليوم: 4 مؤشرات، المتأخرة، جدول متابعات اليوم، عملاء حارّون، أرقام الأسبوع |
| `DeskLeads.dc.html` | العملاء: جدول بأعمدة، فلاتر، ترتيب بالدرجة، تحديد متعدد مع شريط إجراءات |

## لم يُصمَّم بعد

لوحة الأرقام (10)، الإعدادات الكاملة، وضع العرض، أيقونة التطبيق وشاشة البداية. ابنها من المستند ونظام التصميم بنفس الأسلوب.
