# نظام تصميم أُصول

هذا المرجع الوحيد لشكل كل شاشة. أي شاشة تُبنى تقرأ منه ولا تخترع.
والمعاينة الحيّة لكل ما هنا في `معاينة.html` — افتحه في المتصفّح.

---

## القاعدة الأولى: لا قيمة مكتوبة

كل لون وكل حجم وكل مسافة **رمزٌ** من `app/src/styles/tokens.css`.

```tsx
// ✗ يعمل في الوضع الفاتح ويختفي نصّه في الليلي
<div style={{ color: '#fff', background: '#5B6B8C' }}>

// ✓ يعمل في الوضعين بلا سطر إضافي
<div style={{ color: 'var(--sch-on-accent)', background: 'var(--sch-accent)' }}>
```

السبب ليس الأناقة: كل رمز له نظيره الليلي في الملفّ نفسه. واللون المكتوب
بقيمته ليس له نظير — فيبقى كما هو حين ينقلب كل شيء حوله.

**وأخطر حالة**: `#fff` فوق لون يفتحُّ ليلًا. `--sch-success` يصير
`#35C489` في الليل، والأبيض فوقه تباينه **٢٫٢:١** — أي غير مقروء.
لذلك لكل لون حالةٍ رمزُ نصٍّ يقابله:

| الخلفية | النصّ فوقها |
|---------|-------------|
| `--sch-accent` | `--sch-on-accent` |
| `--sch-success` | `--sch-on-success` |
| `--sch-warn` | `--sch-on-warn` |
| `--sch-danger` | `--sch-on-danger` |

---

## الألوان ومعانيها

لكل لون **معنى واحد** لا يتغيّر بين شاشة وأخرى. الموظّف يتعلّم المعنى
مرّة ثم يقرأ الشاشة بلمحة.

| الرمز | المعنى | يُستعمل في |
|-------|--------|-----------|
| `--sch-accent` | الفعل الأساسي، التحديد | الأزرار، الرابط النشط، العنصر المحدَّد |
| `--sch-success` | تمّ · حاضر · مدفوع · في المدرسة | حالة الحضور، الفاتورة المسدَّدة |
| `--sch-warn` | يحتاج انتباهًا لا خطرًا | متأخر، في الباص، عقد يقارب انتهاءه |
| `--sch-danger` | خطر أو خسارة | غائب، متأخر عن الرسوم، إنذار، حذف |
| `--sch-gold` | تميّز وتقدير | الشهادات، التفوّق، الشارات |
| `--sch-muted` | ثانويّ | التسميات، التواريخ، ما لا يُقرأ أولًا |

**والأحمر لا يُستعمل للتزيين.** شاشة فيها ستّة عناصر حمراء لا يميّز
الموظّف فيها ما هو عاجل فعلًا.

### الأسطح

```
--sch-paper        خلفية الصفحة
--sch-surface      البطاقة
--sch-surface-alt  داخل البطاقة (صفّ مميَّز، رأس جدول)
--sch-chrome       الشريط الجانبي والترويسة — داكن في الوضعين
```

القشرة الداكنة ثابتة في الوضعين عن قصد: هي إطار النظام لا محتواه،
وثباتها يعطي الشاشة مرساة بصرية.

## الخطّ

**Cairo** وحده، بثلاثة أوزان فقط: `400` عادي · `600` شبه عريض · `700` عريض.
أربعة أوزان تجعل الشاشة تبدو غير مقصودة.

| الرمز | الحجم | أين |
|-------|-------|-----|
| `--sch-t0` | 11.5px | شارة، تسمية صغيرة، تلميح |
| `--sch-t1` | 13px | نصّ ثانوي، رأس جدول |
| `--sch-t2` | 14.5px | **النصّ الأساسي** — أغلب الشاشة |
| `--sch-t3` | 17px | عنوان بطاقة |
| `--sch-t4` | 22px | عنوان قسم داخلي |
| `--sch-t5` | 28px | عنوان الشاشة، الرقم في الإحصاءة |
| `--sch-t6` | 38px | الرقم الكبير وحده |

**ارتفاع السطر**: `--sch-lh-tight` (1.15) للعناوين · `--sch-lh-base` (1.55)
للفقرات. العنوان بارتفاع سطر الفقرة يبدو مفكّكًا.

### الأرقام

كل رقم في جدول أو إحصاءة يأخذ `className="num"`.
بلا أرقام مُجدوَلة يتغيّر عرض الرقم بين صفّ وصفّ فيرقص العمود كلّه.

والرقم مع وحدته **كتلة واحدة لا تنكسر**:

```tsx
<span style={{ display:'inline-flex', alignItems:'baseline', gap:5, whiteSpace:'nowrap' }}>
  <b>١٬٢٥٠</b><span>ر.س</span>
</span>
```

«١٬٢٥٠ ر.س» مفصولةً بسطر تبدو رقمين لا مبلغًا واحدًا.

## المسافات

سُلَّم واحد: `4 · 8 · 12 · 16 · 24 · 32 · 48` — بالرموز `--sch-s1..s7`.
لا مسافة خارج السُلَّم. الشاشة التي فيها 13px و17px و21px تبدو مهزوزة
ولا يعرف الناظر لماذا.

| الموضع | المسافة |
|--------|---------|
| بين عناصر متلاصقة | `--sch-s2` |
| داخل البطاقة | `--sch-s5` |
| بين البطاقات | `--sch-s4` |
| بين أقسام الصفحة | `--sch-s6` |
| هامش الصفحة | `--sch-s6` |

**الزوايا**: `--sch-radius` (11px) للحقول والأزرار · `--sch-radius-lg` (16px)
للبطاقات · `--sch-radius-xl` (22px) للنوافذ. والشارة `999px`.

## اللبنات

كلّها في `app/src/ui/kit.tsx`. **ابنِ منها قبل أن تكتب مكوّنًا جديدًا.**

| اللبنة | متى |
|--------|-----|
| `<Title>` | عنوان كل شاشة، ومعه سطر يشرح ما تفعله ولمن |
| `<Card>` | كل تجميعة محتوى |
| `<Stat>` | رقم واحد مهمّ، مع وحدته وتسميته |
| `<Grid>` | صفّ إحصاءات أو بطاقات — يلتفّ وحده على الجوّال |
| `<Table>` | كل قائمة سجلات |
| `<Tag>` | حالة: حاضر · متأخر · مسدَّد · معلَّق |
| `<Button>` | فعل |
| `<Field>` | حقل إدخال، ومعه `<label>` مربوط |
| `<Loading>` `<Problem>` | حالتا الانتظار والخطأ |

### حالات لا تُنسى

كل شاشة تعرض بيانات لها **أربع حالات**، وثلاث منها تُنسى عادةً:

1. **تحميل** — `<Loading>`
2. **فارغة** — نصٌّ يقول ما العمل: «لا يوجد طلاب بعد — ابدأ بالاستيراد»
   لا «لا توجد بيانات» وحدها. الشاشة الفارغة الصامتة تبدو معطّلة.
3. **خطأ** — `<Problem>` برسالة عربية مفهومة
4. **فيها بيانات**

## تخطيط الشاشة

```
┌─────────────────────────────────────────────┐
│ العنوان + سطر الشرح                          │  Title
├─────────────────────────────────────────────┤
│ [إحصاءة] [إحصاءة] [إحصاءة] [إحصاءة]          │  Grid + Stat
├─────────────────────────────────────────────┤
│ أدوات: بحث · تصفية · فعل جماعي               │  اختياري
├─────────────────────────────────────────────┤
│ الجدول أو البطاقات                            │  Card + Table
└─────────────────────────────────────────────┘
```

**الترتيب**: ما يحتاج قرارًا أولًا، وما يُقرأ للاطّلاع بعده.
لا تبدأ الشاشة بجدول طويل ثم تضع في آخرها الرقم الذي يهمّ.

### قواعد لا تُخالَف

- **الجدول العريض يمرّر داخل حاويته** (`overflow-x: auto`) — ولا تمرّر
  الصفحة كلّها أفقيًّا.
- **كل حقل له `<label>` مربوط بـ `htmlFor`** — لا نصٌّ فوقه. قارئ الشاشة
  يقرؤه، والنقر عليه يضع المؤشّر في الحقل.
- **الفعل الخطر يسأل مرّة.** الحذف والفعل الجماعي يمرّان بتأكيد — فعل
  جماعي بلا تأكيد يعني خطأً جماعيًّا.
- **من لا يملك الصلاحية لا يرى الزرّ** — لا يضغطه ثم يُمنع.

---

## الوضع الليلي

يعمل تلقائيًّا **إن لم تكتب لونًا بقيمته**. لا تكتب قواعد `[data-theme="dark"]`
في المكوّنات؛ الفرق كلّه في `tokens.css` وحده.

اختبره على كل شاشة قبل التسليم: زرّ التبديل في أعلى يسار الصفحة.

---

## العربية

- كل نصّ للمستخدم عربي، والاتجاه RTL — وهو مضبوط على `<html dir="rtl">`.
- **لا مصطلح تقني في نصٍّ يقرؤه موظّف مدرسة.** لا `sandbox` ولا
  `taught_on` ولا `dashboard`.
- التواريخ بصيغة يفهمها الموظّف: «الأحد ٢٤ صفر» لا `2026-08-19`.
- الأخطاء تقول **ما العمل** لا ما حدث: «البريد أو كلمة المرور غير صحيحة»
  لا «خطأ 401».
