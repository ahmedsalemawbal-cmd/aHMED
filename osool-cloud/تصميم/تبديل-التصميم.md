# تبديل التصميم حين يجهز تصميمك من كلود ديزاين

التصميم الحالي في هذه الحزمة **مؤقّت** — منقولٌ من هوية أُصول القائمة.
وهذا الملفّ يشرح كيف تستبدله بتصميمك، ولماذا لا يتطلّب ذلك إعادة بناء أي شاشة.

---

## مُجرَّب لا موعود

بُدِّلت الهوية كاملةً بتعديل **١٥ رمز لون** في `app/src/styles/tokens.css`
وحده — من سليت رماديّ إلى أخضر زمرّديّ:

| | |
|---|---|
| ملفّات مكوّنات عُدِّلت | **صفر** |
| شاشات أُعيد بناؤها | **صفر** |
| أسطر غُيِّرت خارج `tokens.css` | **صفر** |

فمهما بلغ عدد الشاشات المبنيّة، تبديل الهوية يبقى تعديلًا في ملفّ واحد.

**والشرط الوحيد**: ألّا يكون في أي مكوّن لونٌ مكتوبٌ بقيمته. وهو أول
سطر في `CLAUDE.md` — وسببه الآن واضح: اللون المكتوب بقيمته لا يتبدّل
مع الملفّ، فيبقى وحده على الهوية القديمة وسط شاشة تغيّرت كلّها.

---

## الخطوات

### ① الألوان

افتح `app/src/styles/tokens.css` وبدّل القيم في كتلتَي `:root`
و`:root[data-theme="dark"]`. **بدّل القيم ولا تبدّل أسماء الرموز** —
الأسماء يقرؤها كل مكوّن.

ولكل لون حالة، بدّل معه لون النصّ فوقه:

```css
--sch-accent: #1F6B4A;      /* لونك */
--sch-on-accent: #FFFFFF;   /* النصّ فوقه — تحقّق أن تباينه ≥ 4.5:1 */
```

هذه أكثر خطوة تُنسى. لونٌ جديد بنصٍّ قديم يعطي زرًّا لا يُقرأ.

### ② الخطّ

في `tokens.css`:

```css
--sch-font: 'اسم خطّك', 'Cairo', system-ui, sans-serif;
```

ثم بدّل رابط الخطّ في `app/index.html`. وأبقِ `Cairo` احتياطيًّا بعده:
خطٌّ لا يُحمَّل بلا بديل عربي يترك الصفحة بخطّ النظام الافتراضي، وهو
غالبًا رديء في العربية.

### ③ الأحجام والمسافات

`--sch-t0..t6` للخطّ و`--sch-s1..s7` للمسافات و`--sch-radius*` للزوايا.
بدّلها إن كان تصميمك يستعمل سُلَّمًا مختلفًا.

### ④ شكل اللبنات

إن كان تصميمك يغيّر **شكل** البطاقة أو الجدول أو الشارة — لا لونها فقط —
فالتعديل في `app/src/ui/kit.tsx`. وهو ملفٌّ واحد أيضًا، وكل شاشة تقرأ منه.

### ⑤ التحقّق

```bash
cd app && npm run dev
```

افتح كل شاشة، وبدّل الوضع الليلي على كلٍّ منها. ثم افتح
`تصميم/معاينة.html` — يقرأ `tokens.css` نفسه، فيُظهر الهوية الجديدة
على كل اللبنات دفعةً واحدة.

## إن أردت أن يفعلها كلود كود

أرفق تصميمك وقل له:

```
هذا تصميمي الجديد من كلود ديزاين.

استخرج منه الألوان والخطّ والأحجام والمسافات، وبدّل بها القيم في
app/src/styles/tokens.css — القيم فقط، وأسماء الرموز تبقى كما هي.

لكل لون حالة (accent/success/warn/danger) اضبط معه رمز النصّ فوقه
--sch-on-* بحيث يكون التباين ٤٫٥:١ على الأقل، في الوضعين.

وإن اختلف شكل البطاقة أو الجدول أو الشارة، عدّل app/src/ui/kit.tsx.

ولا تعدّل أي ملفّ في screens/ — الشاشات ترث الهوية ولا تحملها.
ثم شغّل npm run check && npm run build، وأرني لقطة لكل شاشة بالوضعين.
```

آخر سطرين مقصودان: **«لا تعدّل أي ملفّ في screens/»** هو ما يمنع تحوّل
تبديل الألوان إلى إعادة كتابة أربعين شاشة. وإن احتاج تعديلها، فذلك دليل
أن لونًا كُتب بقيمته في مكان ما — فيُصلَح هناك لا يُلتفّ حوله.
