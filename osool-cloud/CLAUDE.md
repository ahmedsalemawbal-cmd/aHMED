# أُصول السحابي — قواعد العمل

هذا المشروع **ليس** إضافة ووردبريس. واجهة ثابتة (Vite + React + TypeScript)
وقاعدة على Supabase. النظام القديم في `../school-system/` ويبقى يعمل — لا تلمسه.

## البنية

```
osool-cloud/
├── supabase/
│   ├── migrations/   ← المخطّط وسياسات الأمان (تُرقَّم ولا تُعدَّل بعد نشرها)
│   ├── tests/        ← اختبار سلوكي لسياسات الأمان
│   └── seed.sql      ← بيانات معاينة
└── app/
    └── src/
        ├── styles/tokens.css  ← كل الألوان والأحجام والمسافات
        ├── ui/kit.tsx         ← اللبنات المشتركة
        ├── lib/               ← عميل Supabase + هوية المستخدم
        └── screens/           ← شاشة لكل قسم
```

## قواعد لا تُخالَف

### الألوان

**لا يُكتب لون بقيمته في أي مكون.** كل لون رمز من `tokens.css`.
لأن كل رمز له نظيره في الوضع الليلي في الملف نفسه — ولونٌ مكتوب بقيمته
يعمل في وضع ويختفي نصّه في الآخر.

```tsx
// ✗
<div style={{ color: '#fff', background: '#5B6B8C' }}>
// ✓
<div style={{ color: 'var(--sch-on-accent)', background: 'var(--sch-accent)' }}>
```

وخاصةً: `#fff` فوق لونٍ يفتحُّ ليلًا يعطي تباينًا ٢٫٢:١. لكل لون حالة
رمزُ نصٍّ يقابله: `--sch-on-accent`, `--sch-on-success`, `--sch-on-danger`.

### الأمان

**الحارس في القاعدة لا في الواجهة.** لا تكتب تحقّقًا في React وتظنّه حماية —
إخفاء الزرّ ترتيبٌ للشاشة، والمنع في سياسة RLS.

- كل جدول جديد يبدأ بـ `enable row level security` **وسياسةً مكتوبة**.
- جدولٌ بلا سياسة مقفلٌ تمامًا — وهذا مقصود.
- بعد أي تعديل على السياسات: `psql ... -f supabase/tests/rls_test.sql`.
- `service_role` لا يدخل ملفّ واجهة أبدًا.

### الترحيلات

مُرقَّمة وغير قابلة للتعديل بعد نشرها. التغيير يكون بملفٍّ جديد.
تعديل ترحيلٍ منشور يعني قاعدتين مختلفتين تحملان الرقم نفسه.

### الشاشات

- شاشة لكل ملفّ في `screens/`، والنموذج `Overview.tsx`.
- ابنِ من `ui/kit.tsx` قبل أن تكتب مكوّنًا جديدًا.
- الأرقام في جدول تأخذ `className="num"` — بلا أرقام مُجدوَلة يرقص العمود.
- الجدول العريض يمرّر داخل حاويته، ولا تمرّر الصفحة أفقيًّا.
- كل حقل له `<label>` مربوط بـ `htmlFor` — لا نصٌّ فوقه.

### اللغة

- كل نصّ للمستخدم بالعربية، والاتجاه RTL.
- التعليقات بالعربية، وتشرح **لماذا** لا **ماذا**.
- لا مصطلح تقني في نصٍّ يقرؤه موظّف مدرسة.

## قبل أن تسلّم

```bash
cd app && npm run check && npm run build
```

كلاهما يجب أن يمرّ بلا خطأ.
