# مِـداد — منصّة الملفّات المدرسية وجداول نور

منصّة اشتراك سعودية تبيع للمدارس والمعلّمين خدمتين منفصلتين تمامًا:

1. **قوالب الملفّات** — مكتبة من 71 ملفًّا مدرسيًّا تُملأ في المتصفّح وتخرج PDF أو وورد أو إكسل.
2. **جداول نور** — إضافة متصفّح تُنزّل الجداول من منصّة نور إلى حساب المشترك.

الخدمتان لا تلتقيان: لا شاشة تخلطهما، ولا زرّ ينقل من إحداهما إلى الأخرى. ومن لا يستعمل نور يستفيد من مِداد كاملًا.

## قاعدة البيانات

سبعة عشر جدولًا، وكلّها محميّة بـ Row Level Security:

| الجدول | ما فيه |
|---|---|
| `subscribers` | المشترك — مدرسة أو معلّم. وهو مالك البيانات. |
| `profiles` | الأعضاء الداخلون تحت المشترك، ولكلٍّ دوره. |
| `roles` | الأدوار الستّة — تحدّد ما يُرى من القوالب لا الصلاحيات. |
| `plans` | الباقات: السعر والمقاعد والفئات المسموحة وحصّة الذكاء. |
| `subscriptions` · `invoices` | الاشتراكات والفواتير والتفعيل اليدويّ. |
| `templates` | مكتبة القوالب: الحقول والمتن بصيغة `{{field}}`. |
| `documents` | ما ملأه المشترك — يُحفظ في حسابه. |
| `noor_tables` · `link_keys` · `noor_ingest_log` | الخدمة الثانية. |
| `ai_usage` | كلّ نداء تحسين، لحساب الحصص والسقف. |
| `platform_settings` | المفاتيح والضريبة وبيانات التحويل وأيّام التجربة. |
| `audit_log` | من فعل ماذا ومتى. |
| `contact_messages` · `push_tokens` · `platform_admins` | التواصل والإشعارات ومالكو المنصّة. |

**العزل مضمونٌ في القاعدة لا في الواجهة:** كلّ استعلامٍ يمرّ بـ RLS، ومشتركٌ لا يرى بيانات مشتركٍ آخر
حتى لو نادى الـ API مباشرةً. والمفاتيح السرّية (ميسر والذكاء الاصطناعيّ) لا تُقرأ إلّا بصلاحية مالك المنصّة.

### تشغيل الهجرات على مشروعٍ جديد

```bash
supabase link --project-ref <ref>
supabase db push                # يطبّق كلّ ملفّات migrations
supabase functions deploy       # ينشر دوالّ الحافّة
```

ثمّ ازرع مكتبة القوالب من `supabase/seed/templates.json`.

## الويب

```bash
cd apps/web
npm install
npm run dev            # تطوير
npm run build          # بناء الإنتاج في dist/
```

نظام التصميم كلّه في `src/ui/midad.css`: الرموز في `:root`، ونسخة داكنة لكلّ رمزٍ لونيّ،
وسابقة `mdd-` لكلّ صنف. والعربية من اليمين **بنيةً لا انعكاسًا** — خصائص منطقية في كلّ مكان
(`margin-inline-start` لا `margin-left`).

### النشر

`deploy/` هو ما تقدّمه دالّة `app`. بعد كلّ بناء:

```bash
cd apps/web && npm run build
cp -r dist/* ../../deploy/
git add ../../deploy && git commit && git push
curl https://<ref>.supabase.co/functions/v1/app/refresh   # يمسح ذاكرة الدالّة
```

### بناء ملفّات المتجر

يلزم حساب Expo مجّانيّ (البناء يجري في سحابة EAS، فلا يلزمك ماك لبناء iOS):

```bash
npm install -g eas-cli
eas login
eas init                            # يملأ extra.eas.projectId في app.json
eas build -p android --profile preview      # ملفّ APK للتجربة المباشرة على جوّالك
eas build -p android --profile production   # AAB لمتجر جوجل
eas build -p ios --profile production       # IPA لمتجر آبل (يلزم حساب مطوّر آبل)
```

`eas build -p android --profile preview` يعطيك رابط تنزيل APK تفتحه من جوّالك مباشرةً.

التطبيق يشترك مع الويب في **قاعدة البيانات والحساب نفسيهما** — تدخل بالجوّال نفسه،
وما تنشئه في التطبيق يظهر في الداشبورد فورًا والعكس.

## إضافة نور

1. افتح `chrome://extensions` في كروم أو إيدج.
2. فعّل **وضع المطوّر**.
3. اضغط **تحميل غير مضغوطة** واختر مجلّد `extension/`.
4. من مِداد: جداول نور ← انسخ مفتاح الربط ← الصقه في الإضافة.
5. افتح كشفًا في نور، واضغط أيقونة مِداد ثمّ «أرسل إلى مِداد».

**الأمان:** الإضافة لا تعمل إلّا حين يضغطها المستخدم (`activeTab` + حقن يدويّ)،
ولا تقرأ كلمة مرور نور، ولا ترسل شيئًا من تلقاء نفسها، والمفتاح يُلغى بضغطة من مِداد.

## ما يحتاج مفتاحًا لتشغيله

| الميزة | ما ينقصها | أين تُضاف |
|---|---|---|
| التحسين بالذكاء الاصطناعيّ | مفتاح Anthropic | لوحة الإدارة ← إعدادات المنصّة ← الذكاء |
| الدفع بالبطاقة | مفتاح ميسر | لوحة الإدارة ← إعدادات المنصّة ← الدفع |

وحتى يصل مفتاح ميسر، الدفع يعمل بالتحويل البنكيّ: المشترك يرى الآيبان ورقم فاتورته،
والإدارة تؤكّد الدفع بضغطةٍ واحدة فيُفتح الاشتراك اثني عشر شهرًا.
التبديل بين الحالتين مبدّلٌ واحد — بلا تغييرٍ في أيّ شاشةٍ أخرى.

## الأدوار

| الدور | يرى من القوالب |
|---|---|
| مدير المدرسة | حقيبة المدير · الخطط · محاضر الاجتماعات · التقارير + العامّة |
| وكيل المدرسة | ملفّات الوكالة · الجداول · المناوبة + العامّة |
| المعلّم | ملفّ الإنجاز · سجلّ المتابعة · التحضير · الاختبارات + العامّة |
| رائد النشاط | خطط الأنشطة · السجلّات · التقارير + العامّة |
| الموجّه الطلابيّ | ملفّات التوجيه · الحالات · البرامج الوقائية + العامّة |

الدور يحدّد **ما يُرى** لا **ما يُمنع**: الغاية أن يجد كلٌّ ملفّاته بلا بحثٍ في إحدى وسبعين ورقة.

## الاستضافة

> **درسٌ مهمّ:** Supabase تستبدل `text/html` بـ `text/plain` في **دوالّ الحافّة والتخزين معًا**
> (سياسة مكافحة تصيّد). فحصٌ مباشر: `text/html` → `text/plain`، بينما `text/css` و
> `application/json` و `image/svg+xml` تمرّ سليمة. لذلك **لا يمكن استضافة الواجهة على Supabase**
> — تظهر نصًّا خامًا لا صفحةً مرسومة.

| **raw.githack.com** (الحالية) | `https://raw.githack.com/ahmedsalemawbal-cmd/aHMED/claude/educational-platform-setup-ct0iwr/midad/deploy/index.html` | تعمل — تقدّم `text/html` صحيحًا |
| رابط قصير (تحويل 302) | `https://ehimyixcqnmnwgbqrdmr.supabase.co/functions/v1/app` | يحوّل إلى githack |
| GitHub Pages (الأفضل للإنتاج) | `https://ahmedsalemawbal-cmd.github.io/aHMED/` | تحتاج تفعيلًا لمرّة واحدة |

**لتفعيل GitHub Pages:** المستودع ← Settings ← Pages ← Source: **GitHub Actions**،
ثمّ من تبويب Actions شغّل سير العمل «نشر مِداد على GitHub Pages».
(صلاحية إنشاء موقع Pages محجوبة عن `GITHUB_TOKEN` الآليّ، فلا بدّ من هذه الضغطة مرّةً واحدة.)

githack مناسبة للتجربة والعرض لا للإنتاج المستمرّ — فهي محدودة المعدّل.
