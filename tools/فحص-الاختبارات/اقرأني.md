# فحص الاختبارات

```bash
php tools/فحص-الاختبارات/run.php
```

٤٧ دعوى تُشغّل `SCH_Exams` **الحقيقيّة** فوق `$wpdb` بجداولَ في الذاكرة —
بلا خادم وبلا قاعدة. والمخزن ليس محرّك SQL: هو صفوفٌ ومقيّمُ شروطٍ بسيطة
(`=` · `<>` · `IS NULL` · `IS NOT NULL`) وهي كلّ ما تكتبه الطبقة. والفائدة
أن **الكتابة تُغيّر الحالة والقراءة التالية ترى ما كُتب** — فالدعوى تختبر
السلوك لا شكل النصّ.

## ما تُثبته

| القسم | الدعوى |
|---|---|
| ① | التواريخ **يومٌ لكل مادة** من قناع أيام المرحلة · **ومدرسةُ السبت لا تُقفَز عليها** |
| ② | **قاعةٌ أو مراقبٌ في شعبةٍ أخرى في اليوم نفسه تعارض** · وفي الشعبة نفسها ليس تعارضًا · وفكّه يُطفئ العلامة |
| ③ | **جدولٌ واحد لكل شعبة في الدورة** — الحفظ ثانيةً يُحدّث ولا يُكرّر · و**اختبارٌ واحد في اليوم** فالوضع يُزيح ساكنه |
| ④ | **مجموع الوزنين مئةٌ دائمًا** · والوزن مقصوصٌ بين ١٠ و٦٠ · **ودرجةٌ فوق وزن نصفها تُرفَض** · والمجموع = النصفان · والنجاح عند ٥٠ |
| ⑤ | **المعذور خارج المتوسط** وحاضرٌ في كشف الدور البديل · وإلغاء العذر يُعيده |
| ⑥⑧ | الإرسال يُقفل الدرجات · وإرسالٌ ثانٍ يُردّ · **وضغطتان متزامنتان على «اعتماد» لا تعتمدان مرّتين** · والاعتماد يُسجَّل |
| ⑦ | `report_card()` تشترط `approved_at` · و`upcoming_exams()` تشترط `published_at` · وقائمة التفوّق من المعتمد وحده · **والترحيل يُعلّم القديم معتمدًا** |
| ⑨ | **من ليس معلّم المادة يُردّ ولو أرسل الطلب مباشرةً** · وشعبةٌ خارج النطاق تُردّ |

## لماذا الدعوى ⑦ موجودة

الاعتماد صار **شرطًا لرؤية وليّ الأمر**. وبلا الترحيل الذي يُعلّم الصفوف
القديمة معتمدةً، تختفي **كل درجةٍ وكل موعدٍ في المدرسة** من أمام الأهل في
اللحظة التي تُرفَع فيها النسخة — لا لأن شيئًا تعطّل، بل لأن عمودًا جديدًا
فارغ. والدعوى تحرس السطر الذي يمنع ذلك.

## وأنها تكشف فعلًا

بكسر ثلاث قواعد في `class-exams.php`:

```bash
# التعارض يشمل الشعبة نفسها          →  ٣ دعاوى تسقط
# القفل بعد الإرسال يُرفَع             →  دعوى تسقط
# الوضع لا يُزيح ساكن اليوم           →  دعوى تسقط
```

## ما لا تغطّيه

- **الذرّية الحقيقية** — `UPDATE … WHERE approved_at IS NULL` تُنفَّذ هنا
  تسلسليًّا؛ وإثبات أثرها تحت التسابق يحتاج MySQL بجلستين. مكانه **بروفة
  التشغيل**.
- **الترحيل نفسه** — يُتحقَّق من وجوده ومن ندائه، وتنفيذه يحتاج قاعدةً حيّة.
