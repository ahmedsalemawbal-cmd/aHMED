# معاينة الداشبورد

يُصيّر شاشة داشبورد حقيقية بلا خادم ولا قاعدة بيانات، فتُقارَن بتصميمها
صورةً بصورة.

```bash
php run.php attendance            > /tmp/dash.html      # أول الصباح: لم يُمسح أحد
DEMO=mid php run.php attendance   > /tmp/dash-mid.html  # منتصف الطابور
THEME=dark php run.php attendance > /tmp/dash-dark.html # الوضع الداكن
```

**لماذا لا تُحاكى القشرة؟** الشريط الجانبي والمسار العلوي ليسا من الشاشة،
وقشرةٌ مقلَّدة تُدخل فروقًا ليست منها. أمّا الورقتان (`shared-ui.css` ثم
`dashboard.css`) فتُحمَّلان بترتيبهما في `layout.php` — فأي تصادم بين
الملفّين يظهر هنا كما يظهر في الإنتاج.

**والمحاكاة تطابق الطبقة حرفًا بحرف.** ما اختلف شكلُه هنا عن شكله في
`modules/` يجعل المعاينة تُخفي عطلًا أو تخترعه — وقد وقع ذلك مرارًا:
دالّةٌ تُرجع خريطة فقُلّدت قائمةً، فبدت الشاشة سليمة وهي مكسورة.
