# مدرسة الفلك المنير — إضافة ووردبريس

طبقة واجهة عربية (RTL) كاملة لموقع **«مدرسة الفلك المنير لتحفيظ القرآن الكريم»**،
مبنية على نمط إضافة `osoul-site` لكن مبسّطة ومخصّصة لمدرسة تحفيظ قرآن، بهوية
**أخضر / أبيض / ذهبي** وخط `Tajawal` مع عناوين مصحفية `Amiri`.

> إضافة واحدة مستقلّة (بدون قالب خاص) تعمل فوق أي قالب ووردبريس بسيط: تُخفي إطار
> القالب وترسم ترويستها وتذييلها وصفحاتها بعرض كامل.

---

## المميزات

- **واجهة عربية RTL** حديثة وأنيقة بألوان أخضر/أبيض/ذهبي وزخارف إسلامية هندسية.
- **صفحات جاهزة:** الرئيسية، من نحن، البرامج، المعلمون، معرض الصور، الأسئلة الشائعة، تواصل معنا، التسجيل.
- **قسمان:** البنين (حضانة → السادس الابتدائي) والبنات (حضانة → الثالث الثانوي).
- **إدارة البرامج** من لوحة التحكم (نوع محتوى «البرامج») مع أيقونة وشارة ووسوم لكل برنامج.
- **نظام تسجيل حقيقي:** نموذج يُحفظ في قاعدة البيانات + إشعار بريد للإدارة + رجوع لواتساب عند التعذّر،
  محميّ بـ nonce و honeypot و rate-limit. تُدار الطلبات من **لوحة التحكم → التسجيلات**.
- **إعدادات بلا كود:** كل معلومات التواصل والهوية والإحصائيات تُدار من **التسجيلات → إعدادات الموقع**.
- **أداء:** CSS/JS في ملفات مخزّنة (cache) بإصدار `filemtime`، وخطوط جوجل بـ `preconnect`.
- **SEO/أمان/أيقونة:** ميتا و Open Graph و schema.org، رؤوس أمان، وأيقونة موقع نظيفة.

---

## التركيب

1. انسخ مجلّد `falak-site/` إلى `wp-content/plugins/`.
2. من **لوحة التحكم → الإضافات**، فعّل **«مدرسة الفلك المنير»**.
   - عند التفعيل تُنشأ الصفحات المطلوبة، وتُزرع البرامج الافتراضية، وتُعيَّن الصفحة الرئيسية.
3. من **الإعدادات → الروابط الدائمة**، اختر أي نمط عدا «عادي» (Plain) لتعمل روابط الصفحات.
4. عدّل بيانات المدرسة من **التسجيلات → إعدادات الموقع** (الاسم، الجوال، واتساب، البريد، العنوان،
   الإحصائيات، وسائل التواصل، رابط الشعار، خريطة جوجل).

> لا حاجة لأي خطوة بناء (build). PHP/CSS/JS خام. يتطلّب ووردبريس 5.8+ و PHP 7.4+.

## التخصيص

- **الهوية ومعلومات التواصل والإحصائيات:** التسجيلات → إعدادات الموقع (بدون كود).
- **البرامج:** لوحة التحكم → البرامج (إضافة/تعديل/حذف).
- **الألوان والخطوط:** متغيّرات التصميم في أعلى `assets/css/falak.css` (تُغيّر الموقع كله من مكان واحد).
- **الشعار:** ألصق رابط صورة PNG مربّعة في حقل «رابط الشعار» بالإعدادات؛ وإلا تظهر أيقونة افتراضية.
- **بريد إشعار التسجيل:** فلتر `falak_enroll_notify_email`.
- **ربط الطلبات بأنظمة خارجية (CRM/واتساب API):** خطّاف `do_action('falak_enroll_received', $id, $data)`.

## أداة المعاينة (اختيارية)

مجلّد `preview/` يحتوي أداة تُشغّل قوالب الإضافة الحقيقية خارج ووردبريس لإنتاج
معاينة HTML ثابتة (تُستخدم أثناء التطوير للتصوير). ليست جزءًا من عمل الإضافة:

```bash
php preview/render.php > preview/index.html     # الصفحة الرئيسية
FALAK_PAGE=enroll php preview/render.php > preview/enroll.html
```
