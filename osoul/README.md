# أصول البناء — المنصّة

نقلُ موقع [osoulalbinaa.com](https://osoulalbinaa.com) من إضافةِ ووردبريس
(`osoul-site`, ‏v2.22.3) إلى مشروعٍ مستقلٍّ على جيت‑هَب وسوبابيز، بالبنية
التي عليها `midad/`.

## البنية

```
osoul/
├── apps/web/          Vite 5 + React 18 + TypeScript — الموقعُ والبوّابات معًا
│   ├── src/ui/        osoul.css (الرموز) · kit.tsx · icons.tsx
│   ├── src/lib/       supabase · store · i18n · dict · format · theme · hooks · config
│   ├── src/pages/     site · auth · portal · partner · mail · admin
│   ├── tests/         فحوصٌ بلا إطار (run.mjs) + lib/browser.mjs
│   ├── routes.json    المساراتُ العامّةُ وعناوينُها — يقرؤها الرسمُ المسبق
│   └── prerender.mjs  يرسم كلَّ مسارٍ عامٍّ ملفَّ HTML مكتملًا
├── supabase/
│   ├── migrations/    الجداولُ والسياساتُ والدوالُّ والبذور
│   ├── functions/     دوالُّ الحافّة (دينو)
│   └── tests/         wall.sql — فحصُ السياسات بانتحال الهويّة
└── tools/import-wp/   مستورِدُ بيانات ووردبريس (بايثون)
```

## التشغيل

```bash
cd osoul/apps/web
npm install
npm run dev        # http://127.0.0.1:4190
npm run build      # فحصُ الأنواع ثمّ البناء ثمّ الرسمُ المسبق
npm test           # الفحوص
node tests/shot.mjs /            # صورةُ الصفحة من البناء (فاتحٌ وداكن)
```

## المشروع على سوبابيز

`bnixzzhcnfjdfmtiwjvr` — فرانكفورت (`eu-central-1`)، وهو **أقربُ إلى الرياض**
من سنغافورة التي عليها مِداد. ومشروعٌ منفصلٌ تمامًا: لا جدولَ مشتركًا ولا مفتاح.

## ثلاثةُ ثوابتَ أمنيّةٍ تُفرَض في القاعدة لا في الواجهة

**① جدارُ خصوصيّة الشركاء.** الشريكُ يشتري بسعر تكلفةٍ ويبيع لعميله بعلامته.
وعروضُه لعملائه (`kind='cust'`) **لا تراها أصولُ أبدًا — ولا المدير**. ويُفرَض
بسياسةٍ `as restrictive` تُجمع بـ«و» لا بـ«أو»، فلا تنقضها سياسةٌ تُكتب غدًا.

**② المالُ لا يُحجَب في الواجهة.** السعرُ جدولٌ منفصل (`quote_prices`)، فالمندوبُ
لا يرى صفَّه أصلًا حتّى يُصدِر المديرُ العرض. ولو نادى `/rest/v1/quote_prices`
بيده رجع بمصفوفةٍ فارغة.

**③ لقطةُ العلامة تُختم ولا تُفكّ.** هويّةُ الشريك تُنسخ في `quotes.brand` لحظةَ
الإصدار، ومُحفِّزٌ يمنع تبديلَها بعده — فالعرضُ الذي سُلّم في ٢٠٢٤ يحفظ شعارَ
٢٠٢٤ ولو بدّل الشريكُ شعارَه اليوم.

يفحصها `supabase/tests/wall.sql` بانتحال هويّةِ مستخدمين حقيقيّين:

```bash
psql "$DATABASE_URL" -f osoul/supabase/tests/wall.sql
```

## الفروقُ المقصودةُ عن مِداد

| | مِداد | أصول البناء |
|---|---|---|
| العزل | `subscriber_id` في كلّ جدول | **الدورُ والملكيّة** — شركةٌ واحدة |
| التوجيه | `HashRouter` | **`BrowserRouter` + رسمٌ مسبق** — موقعٌ يُؤرشَف |
| اللغة | عربيٌّ وحده | **ثلاثيّ** (ar · en · ur) بقاموسٍ مأخوذٍ من الإضافة |
| الخطّ | Cairo | IBM Plex Sans Arabic — **مستضافٌ محلّيًّا** (٣ أوزان) |
