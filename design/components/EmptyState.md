# EmptyState

حالة فارغة تشرح لماذا لا يوجد شيء، وتعرض إجراءً واحداً واضحاً.

**يوفّر المستهلك:** `title`، `message`، `action` (زر `Button` واحد). اختياري: `icon` (`pin`، `store`، `chat`، `check`، `clock`).

- كل شاشة لها حالتها الفارغة: اليوم → «انزل للميدان» + «عميل جديد»؛ المهام → «لا مهام اليوم»؛ نتائج البحث → «لا يوجد محل بهذا الاسم» + «امسح البحث».
- عنوان قصير يقول الحال، وسطر يقول ما الخطوة التالية. بدون رسومات توضيحية.
