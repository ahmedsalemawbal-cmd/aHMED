# التسويق — مدرسة الفلك المنير

مستندات الحملة التسويقية العاجلة لموسم التسجيل **2026 / 2027** (من الحضانة حتى الثانوية بنات، وبنين حتى الصف السادس).

## المحتويات

- **الخطة التسويقية** — `Marketing-Plan-AlFalak-AlMuneer.docx`
  الفكرة الاستراتيجية، مكوّنات الحملة (الأساس + الإضافات الرافعة للتحويل)، مسار التحويل، الجدول الزمني العاجل، ومؤشرات قياس النجاح.

- **العرض الفني والمالي — نسخة بهوية النخبة الرائدة** (النهائية) — `Proposal-AlFalak-AlMuneer-Branded.docx`
  العرض معاد تصميمه على قالب «النخبة الرائدة» (خط Cairo، الهوية البنفسجي/البرتقالي، ترويسة وتذييل بالشعار). يتضمّن ٧ أقسام فنية + العرض المالي بنموذج شراكة: **رسوم ثابتة 3,900 ريال + عمولة نجاح 10% لكل طالب جديد يُسجَّل عبر الموقع**، مع يشمل / لا يشمل وآلية الدفع.

- **العرض الفني والمالي — نسخ أولية** — `Proposal-Technical-Financial-AlFalak-AlMuneer.docx`
  نسخة عامة سابقة (تسعير 5,600 ريال). النسخة المعتمدة هي المصمّمة بالهوية أعلاه.

## قبل الإرسال للعميل

- عبّئ الحقول بين الأقواس `[ ... ]`: اسم المزوّد/الوكالة، رقم الجوال، البريد الإلكتروني.
- راجع/عدّل قيمة الخصم والموعد النهائي في «العرض المحفّز» حسب ما يُتفق عليه.
- ميزانية الإعلانات الممولة تُدفع مباشرةً للمنصات وهي مستقلة عن قيمة العرض.
