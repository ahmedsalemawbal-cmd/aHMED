# أُصول — قشرة تطبيق وليّ الأمر (Expo)

غلافٌ يعرض تطبيق وليّ الأمر الذي يعيش في الإضافة على خادم المدرسة،
ويعطيه ما لا يعطيه المتصفّح: أيقونة على الشاشة، وفتحًا بملء الشاشة،
وطريقًا إلى المتجر.

## لماذا لا يُحقن فيه عنوان مدرسة واحدة

نسخة لكل مدرسة تعني بناءً ورفعًا للمتجر مع كل عميل جديد، ومراجعةَ أبل
في كل مرّة. فالعنوان يُسأل عنه مرّة عند أول تشغيل ويُحفظ — **وبناء واحد
يخدم كل مدارسك**.

---

## التجربة على جهازك — خطوة بخطوة

### ① على اللاب توب

```bash
cd osool-expo
npm install          # أول مرة فقط، ٢–٣ دقائق
npx expo start
```

يظهر **باركود في الطرفية**. هذا هو الباركود الذي تسأل عنه — يُولَّد على
جهازك لأنه يشير إلى خادم التطوير الذي يعمل عندك.

### ② على الآيفون

افتح **الكاميرا** (لا Expo Go) ووجّهها للباركود، ثم اضغط الإشعار.
يفتح Expo Go ويحمّل التطبيق.

> **شرطٌ لا بدّ منه:** الجوّال واللاب توب على **نفس شبكة الواي فاي**.
> وإن تعذّر (شبكة الشركة تعزل الأجهزة مثلًا) فشغّل:
> ```bash
> npx expo start --tunnel
> ```
> يمرّ عبر الإنترنت فيعمل من أي شبكة، لكنه أبطأ.

### ③ داخل التطبيق

يسألك عن **عنوان موقع المدرسة**. اكتبه بلا `https://`:

```
madrasati.com
```

ثم تدخل بحساب وليّ أمر، فيظهر التطبيق بتصميمه الجديد.

---

## قبل أن تجرّب

الإضافة **يجب أن تكون مرفوعة ومُفعَّلة** على الموقع، وفيها حساب وليّ أمر
مرتبط بطالب. القشرة لا تحمل بيانات — هي نافذة على موقعك.

---

## ما الذي يعطيه الغلاف زيادةً على Safari

| | |
|---|---|
| الجلسة تبقى | لا يُطلب الدخول كل مرّة |
| زرّ الرجوع | يرجع صفحةً داخل التطبيق لا يخرج منه |
| الروابط الخارجية | تفتح في المتصفّح، فلا يفقد الأب طريق العودة |
| انقطاع الشبكة | شاشة مفهومة وسحبٌ للتحديث، لا صفحة خطأ بيضاء |
| تغيير المدرسة | متاح بلا حذف التطبيق |

---

## بعد التجربة — نحو المتجر

Expo Go للتجربة وحدها. وللنشر على App Store:

```bash
npm install -g eas-cli
eas login
eas build --platform ios --profile production
eas submit --platform ios
```

ويلزمك حساب **Apple Developer** (٩٩ دولارًا سنويًّا).

> والإشعارات الفوريّة تحتاج قناة APNs مستقلّة عن إشعارات الويب التي في
> الإضافة — تُضاف قبل النشر لا قبل التجربة.
