# أوامر جاهزة لكل مرحلة

انسخ الأمر كما هو إلى Claude Code، واحداً بعد الآخر. لا تنتقل للتالي حتى تجرّب الحالي.

---

## 0 · الإعداد

```
اقرأ CLAUDE.md و docs/decisions.md و docs/brief.md.
نفّذ المرحلة 0 فقط:
- مشروع Vite + React + TypeScript + Tailwind في جذر المستودع، بواجهة RTL وخط IBM Plex Sans Arabic.
- انسخ design/tokens.css إلى src/styles واربط Tailwind بمتغيراته.
- عميل Supabase من متغيرات البيئة، وملف .env.example (بدون قيم حقيقية).
- مجلد supabase/migrations فيه كل الجداول والقيم المغلقة من المستند بعد تعديلات decisions.md، مع RLS على كل جدول، وseed بأنشطة وخدمات وبنود تقييم تجريبية.
- شاشة الدخول حسب design/screens/Login.dc.html، وحماية باقي الصفحات.
- PWA قابل للتثبيت (manifest + service worker).
اعرض الخطة أولاً.
```

## 1a · مكونات نظام التصميم

```
أعد كتابة مكونات design/components/bundle.js كمكونات React + TypeScript في src/components/ui
(Button, TextField, StageBadge, PriorityBadge, LeadCard, ScoreBar, TriSelect, BottomSheet, Toast, EmptyState)
بنفس الـ props في index.d.ts والشكل في bundle.css وإرشادات design/components/*.md.
أضف صفحة /dev/ui تعرضها كلها بالوضعين الفاتح والداكن.
```

## 1b · الهيكل والتنقل وشاشة اليوم

```
ابنِ الهيكل: شريط سفلي على الجوال (design/screens/BottomNav.dc.html) وشريط جانبي يميناً على الديسكتوب (DeskSidebar.dc.html)، وزر «عميل جديد».
ثم شاشة اليوم بنسختيها (Main.dc.html و DeskToday.dc.html) ببيانات حقيقية من Supabase وحالاتها الخمس.
```

## 1c · عميل جديد والتقييم

```
ابنِ معالج «عميل جديد» بخطواته الأربع حسب NewLead1..4.dc.html:
حفظ مسودة تلقائي، كشف التكرار (نفس الرقم أو نفس الاسم في نفس الموقع)، تحويل الجوال إلى 9665، حساب الدرجة مباشرة (نعم = الوزن، جزئي = نصفه، لا = 0)، نقاط الضعف، اقتراح الخدمات، والأولوية حسب قواعد المستند.
رفع الصور والفيديو إلى Storage. الإدخال الصوتي اتركه زراً معطلاً بعلامة «قريباً» (مرحلة 2).
```

## 1d · الرسالة والواتساب

```

ثم شاشة الرسالة و«هل أرسلت؟» حسب Message.dc.html و SentConfirm.dc.html: رابط wa.me، تسجيل sent_at بعد التأكيد فقط، المرحلة contacted، ومتابعتان بعد 3 و7 أيام.
```

## 1e · العملاء وصفحة العميل

